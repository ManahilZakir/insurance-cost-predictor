## 📊 Project Overview
This machine learning project uses a **Random Forest Regressor** to predict annual medical insurance costs based on parameters such as age, BMI, smoker status, number of children, and region.

## 📁 Repository Contents
* **`P35_Insurance_Cost_Estimator.ipynb`**: Complete Jupyter/Kaggle notebook containing data preprocessing, visual analysis, model training, and performance metrics.
* **`app.py`**: Streamlit application script for the interactive user interface.
* **`insurance_rf_model.pkl`**: Saved Random Forest model.
* **`model_columns.pkl`**: Saved feature column order.
* **`requirements.txt`**: Python dependencies required to run the project.
